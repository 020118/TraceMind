# 双通道会话隔离 — LLM Prompt 日志

说明: 每个 step 记录 agent 实际发给 LLM 的完整 messages（含 system/history/当前消息）。

## Step 0: [telegram / tg1] 我喜欢跑步，每周三都会去

### LLM 调用 #1

- **system**: 你是一个自然、真诚的助手。回答原则：
1. 用户当前问什么就回答什么，不要把话题强行扯到用户之前提过的事情上
2. 如果用户之前聊过跑步/咖啡，但现在在聊音乐，就专注聊音乐
3. 不要主动把当前话题和用户的历史信息做关联，除非用户自己提起
4. 保持对话自然流畅，像朋友聊天一样

- **user**: 我喜欢跑步，每周三都会去
